# Voice AI Agent 🎙️🤖

A real-time, low-latency conversational AI voice agent. This project features a full-duplex communication pipeline where the user can speak naturally, and the AI responds in real-time with streaming speech-to-text (STT), large language model (LLM) generation, and text-to-speech (TTS).

## Features ✨
- **Real-Time Streaming**: Audio is streamed via WebSockets from the frontend to the backend for instantaneous processing.
- **Barge-in Support**: The user can interrupt the AI at any time. The system will detect the interruption and cancel the ongoing AI speech.
- **Fast Speech-to-Text (STT)**: Powered by **Deepgram** (Nova-2 model) for ultra-fast and accurate speech recognition.
- **Lightning Fast LLM**: Integrates with **Groq** and **LangChain** (Llama-3) to generate streaming text responses in milliseconds.
- **Streaming Text-to-Speech (TTS)**: Uses **Deepgram TTS** to stream audio back to the client as soon as the first sentence is generated by the LLM.
- **Modern Frontend**: Built with **Next.js** and React hooks, using raw `AudioWorklet` to capture and transmit `int16` PCM audio efficiently.

## Architecture 🏗️

The project is divided into two main parts:
1. **Frontend (`/frontend`)**: A Next.js web application that captures microphone input, sends raw PCM audio over WebSockets, and plays back the AI's audio responses.
2. **Backend (`/backend`)**: A FastAPI Python server that orchestrates the WebSockets, Deepgram STT, Groq LLM, and Deepgram TTS services.

## Prerequisites 🛠️

- Node.js (v18+)
- Python 3.10+
- [Deepgram API Key](https://deepgram.com/)
- [Groq API Key](https://groq.com/)

## Getting Started 🚀

### 1. Backend Setup (Optional - Hosted on Hugging Face)
The backend for this project is currently hosted on Hugging Face. If you want to run the frontend against the hosted backend, you can skip this step!

If you prefer to run the backend locally, navigate to the `backend` directory and install the required Python packages.

```bash
cd backend
python -m venv venv

# On Windows (Command Prompt / PowerShell):
.\venv\Scripts\activate

# On Windows (Git Bash):
source venv/Scripts/activate

# On Mac/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

Create a `.env` file in the `backend` directory and add your API keys:
```env
DEEPGRAM_API_KEY=your_deepgram_api_key
GROQ_API_KEY=your_groq_api_key
```

Start the FastAPI server:
```bash
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 2. Frontend Setup
Open a new terminal, navigate to the `frontend` directory, and install dependencies.

```bash
cd frontend
npm install
```

Start the Next.js development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Grant microphone permissions when prompted, and start talking! 

## How It Works 🧠
1. **Audio Capture**: The Next.js frontend uses an `AudioWorklet` to capture `float32` PCM audio, converts it to `int16`, and streams it over a WebSocket to the FastAPI backend.
2. **Transcription**: The backend streams the raw audio directly to Deepgram STT.
3. **Response Generation**: When silence is detected (utterance complete), the transcribed text is sent to Groq (Llama-3).
4. **Chunking & TTS**: The LLM output is streamed and chunked into logical phrases. Each phrase is sent to Deepgram TTS.
5. **Playback**: The generated audio chunks are streamed back over the WebSocket to the frontend for seamless playback.
